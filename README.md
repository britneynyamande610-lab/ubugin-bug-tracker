# U-BugIn — Bug Tracking Web Application

U-BugIn is a dynamic web-based issue tracking system designed to streamline bug reporting, task assignment, and workflow management for development teams.

## 🚀 Features
* **User Authentication**: Secure login and sign-up interface.
* **Interactive Analytics**: Real-time visual metrics of open, in-progress, and resolved issues powered by Chart.js.
* **Issue Management**: Create, assign, filter, and track software bugs across their lifecycle.
* **Client-Side Data Persistence**: State retention and data management using the Web Storage API (`localStorage`).

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Visualization**: Chart.js
* **Storage**: Web Storage API (`localStorage`)

## 💻 How to Run Locally
1. Clone or download the repository.
2. Open the project directory in **Visual Studio Code**.
3. Launch `Home.html` or `login.html` using **Live Server**.
